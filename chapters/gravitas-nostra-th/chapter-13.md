## 「 13. The Deadly Delusion 」

### CHAPTER THIRTEEN

#### The Deadly Delusion

⚠️ คำเตือน: ตอนนี้มีเนื้อหาเกี่ยวกับ **การล่วงละเมิดทางเพศ**

ธัชชัย:

ผมนี่รู้สึกว่าเป็นคนนอกเลย เมื่อเห็นเควินถูกรายล้อมไปด้วยเพื่อนๆ โต๊ะนั้นทั้งโต๊ะนอกจากเควินแล้ว ผมรู้จักอยู่แค่สองคนเอง ก็คือเอิ้นกับตั้ม สำหรับผมแล้ว ตั้มเป็นแค่เด็กเนิร์ดเงียบๆ แต่ว่าเอิ้นชอบกันท่า ไม่ให้ผมอยู่ใกล้เควิน ซึ่งผมก็ไม่รู้ว่าทำไมหรอกนะ แต่ผมโคตรไม่ชอบเอิ้นเลย แล้วคนที่ตายก็อีก เขาเป็นเพื่อนกลุ่มนั้นหรอ เห็นเศร้ากันทั้งโต๊ะ แต่ผมกลับไม่รู้เรื่องอะไรเลย มันยิ่งทำให้ผมรู้สึกแปลกแยก ตอนนี้ไม่ได้มีอารมณ์อยากจะกินอะไรเลยแม้แต่น้อย แม้ว่าแจ็คจะสั่งข้าวผัดมาให้ผมแล้วก็ตาม

“กินอะไรบ้างสิวะ” ผมจ้องมองที่จานข้าวผัดของตัวเอง กับน้ำอัดลมที่ยังไม่ได้แตะ สลับกับจานข้าวที่กินไปแล้วกว่าครึ่งหนึ่งของแจ็ค กับกระป๋องเบียร์สามกระป๋องที่ยังไม่ได้เปิดของเขา “นอกจากนี่ กูยังมีโรตีอยู่ในรถนะ โรตีธรรมดาไม่ใส่ไข่ของโปรดของมึงไง บางกรอบ และเปราะบางเหมือนเดิม... ส่วนของกู โรตีหนานุ่มใส่ไข่ อย่าหยิบผิด”

แจ็คก็ยังเป็นแจ็ค ยังคงซื้อโรตีแบบเดิมไม่มีเปลี่ยน ตั้งแต่เด็กๆ สมัยที่อยู่โคราชแล้ว

แต่ในหัวผมคิดย้อนไปถึงอดีต ตอนที่ผมได้ใช้เวลากับเควินสองคน ไม่ว่าจะเป็นตอนที่เขาช่วยผมติวข้อสอบเพื่อเข้ามหาวิทยาลัยแห่งนี้ ซึ่งเป็นมหาวิทยาลัยนานาชาติ ทุกอย่างเป็นภาษาอังกฤษทั้งหมด ผมใช้เวลาหนึ่งปีในการฝึกฝนภาษา ทำโจทย์เลข และออกแบบโปรแกรมง่ายๆ ทุกวัน ผมจะนั่งนับรอวันเสาร์อาทิตย์ ที่เป็นวันที่ผมกับเควินจะได้เจอกันที่สยาม ที่เราเรียนพิเศษด้วยกัน

‘นี่ไง เมื่อกี้นี้ก็เรียนเรื่องนี้มาแล้วไม่ใช่หรอ? What is the prime number? Think! What is it? (จำนวนเฉพาะคืออะไร? คิดสิ! มันคืออะไร?)’

‘พาม นัมเบ้อ คือ นัมเบ้อที่มีดีวายเด้อคือหนึ่งกับตัวมันเอง’ ผมพยายามเค้นคำตอบออกมาจากหัว แต่ก็ทำได้เพียงแค่นี้ นมปั่นที่สั่งเอาไว้ ตอนนี้ละลายหมดแล้วก็ยังไม่ได้แตะ ผมหันไปหาเควินที่กำลังลองฝึกทำโจทย์ข้อที่ 23 แล้ว ส่วนผมเพิ่งอยู่ที่ข้อห้าเอง

เฮ้อ... ชีวิตผมก็เหมือนจำนวนเฉพาะนั่นแหละ มีตัวหารได้สองตัวก็คือผมกับเคฟสองคนเท่านั้น... จะมีใครเหมาะสมกันไปมากกว่านี้? ไม่มีอีกแล้ว

‘หันมามองทำไม ไม่ทำโจทย์ต่อ?’ เขาไม่ต้องเงยขึ้นมามองก็รู้ผมว่าแอบมองเขาอยู่ ‘หารลงตัวได้ด้วยหนึ่งกับตัวของมันเอง แล้วจะเช็กได้ยังไง?’

‘ลูปหรอ?’

‘ลูป ใช่ ประเภทไหน?’

‘วายหรอ?’

‘ประเภท while โอเค ไหนลองเขียนฟังก์ชันซิ’ เควินออกเสียงย้ำชัดๆ ว่าคำว่า while ไม่ได้อ่านว่า ‘วาย’

ผมหันไปมอง เควินทำถึงข้อ 24 ที่เป็น Fibonacci sequence แล้ว (มันคือเลขบ้าบออะไรผมยังไม่รู้เลย) แต่เขาก็หันมาสอนผมด้วย แบบฝึกหัดนี้มี 25 ข้อ และเขากำลังจะทำเสร็จ แต่ว่าผมนี่สิ รู้สึกตัวเองโชคดีมากที่มีคนใจดีอย่างเควินช่วยผมขนาดนี้ รู้สึกมีกำลังใจในการเรียนอย่างมาก

และในขณะที่เควินกำลังทำโจทย์ของตัวเอง ผมก็เริ่มจับปากกาเขียนโค้ดบนชีทแบบฝึกหัดของผมเองบ้าง

```
let isPrime = function (n) {
  let i = 1;
  while ( i <= n && 0 != n % i ) {
    i++;
  }
  if ( i === n ) {
    return true;
  } else {
    return false;
  }
}
```

พอเสร็จ ผมก็ยื่นให้เควินดูอย่างเก้ๆ กังๆ ไม่มีความมั่นใจ เพียงแค่ไม่กี่อึดใจเควินก็วางดินสอลงและหันมามองที่ชีทของผม

‘ผิด ลองใส่หนึ่งเข้าไปสิ เดี๋ยวก็รู้เอง’

สองวินาที!

เควินใช้เวลาเพียงสองวินาทีก็มองออกแล้วว่ามันผิด และบอกให้ผมลองแทนค่าที่ผิดได้ด้วย! ผมลองค่อยๆ คิด และมันก็ผิดจริงๆ จำนวนเฉพาะ คือเลขที่มีตัวหารลงตัวคือหนึ่งกับตัวมันเอง รวมสองตัว ดังนั้น เลขหนึ่งจึงไม่ใช่จำนวนเฉพาะ

‘เรามันโง่มากใช่มั้ยอะเควิน’

เควินวางดินสอระหว่างกำลังเขียนคำตอบข้อสุดท้ายของเขา ก่อนที่จะหันมายิ้มให้ผม และพูดว่า ‘Do not think like that. You just never knew it before. (อย่าคิดอย่างนั้นสิ นายแค่ยังไม่เคยรู้มาก่อน)’

ผมแทบจะตั้งตัวไม่ถูก ที่รู้สึกว่าตัวเองโง่ หรือเอาจริงๆ ตัวเองก็ไม่ได้โง่กันแน่ ผมงงไปหมดแล้ว

‘ลองดูนี่นะ’ เควินพลิกหน้าแบบฝึกหัดของเขากลับมายังคำถามข้อที่ห้า ผมลองดูที่คำตอบของเขาที่มีแค่สามบรรทัดหลักๆ สั้นๆ ง่ายๆ และเอ่อ ดูเหมือนว่าเขาจะตรวจสอบ input ก่อนด้วยว่าใช้ได้หรือไม่ ถ้าใช่ไม่ได้ ก็ตอบทันทีเลยว่าผิด และนอกจากนั้น แทนที่เขาจะใช้ if/else ในการเช็กค่าว่า i เท่ากับ n หรือไม่ เขากลับที่เช็กได้ส่งค่าคืนไปเลย

```
let isPrime = function(n){
  if(!Number.isInteger(n)||n<2)return!1;
  let i=2; while(i<=n&&0!=n%i){i++;}return i===n;
}
```

ผมใช้เวลาสามชั่วโมงในการเรียนกับเควินวันนั้น จนเริ่มค่ำ จึงได้แยกย้ายกันกลับ ถึงแม้ว่าเควินจะได้รับข้อความจากเพื่อนที่ชวนไปกินข้าวกัน ชวนไปดูหนังกัน เขาก็ไม่ไป เขาใจดีกับผมมากจริงๆ แบบนี้ไม่ให้ผมรักเควินก็ไม่รู้ว่าจะว่ายังไงแล้ว ทุกวันเสาร์อาทิตย์ ผมจะมีความสุขแบบนี้แหละครับ ตอนนั่งรถไฟฟ้ากลับบ้าน ผมมักจะเปิดเพลงรักฟังเสมอ

“เฮ้ย! ธัชชัย! จะเหม่อไปถึงไหน?”

ผมถูกดึงให้หลุดจากภวังค์โดยนายแจ็คคนเดิมครับ ไม่รู้เมื่อกี้นี้จะลากผมมาตรงนี้ทำไม ผมอยากจะอยู่ปลอบเควินเหมือนกันนะ ดูสิ ตอนนี้ จะเป็นยังไงบ้างก็ไม่รู้แล้ว แจ็คนะแจ็ค คนใจร้าย!

“ไม่รู้เควินจะเป็นยังไงบ้าง”

“นั่นมันกลุ่มเพื่อนเขา ปล่อยให้เขาได้ทำใจไป มึงเป็นคนนอก ให้พื้นที่เขาได้เศร้าบ้าง”

“เขาเศร้าก็ต้องปลอบสิ”

“**ธัชชัย!**” แจ็คขึ้นเสียงใส่ผมเฉยเลย “กูบอกให้มึงไปบอกชอบมันมาตั้งแต่กี่โมงมิทราบ มึงจะได้เป็นคนใน! นี่มึงไม่ยอมไปเอง มึงจะมาโกรธใคร?”

จุก! แต่ว่าใครล่ะ มีแต่คนคอยที่จะกันไม่ให้ผมเข้าไปใกล้กับเควินที่รักของผม ไม่มีใครอยากให้ผมอยู่ใกล้เขาเลย มันก็เป็นความผิดของเอิ้นกับแจ็คนั่นแหละ!

ผมจุกจริงๆ แต่ผมก็ไม่อยากจะสนใจอะไรแล้ว ผมรีบคว้าเอาเบียร์ตรงหน้าแจ็คมาแล้วเปิดดื่มทันทีก่อนที่แจ็คจะทันได้ห้าม “**เฮ้ยๆๆๆๆ มึงๆๆๆๆ เบาๆๆๆๆ!!! เดี๋ยวก็ติดคอตายกันอีกคนพอดีเฮ้ย!**”

เอาให้เมาไปเลย คืนนี้ที่คิดว่าจะกลับไปอ่านหนังสือเพราะเควินขู่ว่าจะไม่ติวแล้วให้ถ้าผมได้คะแนนควิซครั้งหน้าไม่ถึงครึ่ง ผมก็ไม่อยากจะติวแล้วครับ เพราะยังไง ทุกคนก็พยายามขวางผมไม่ให้เข้าใกล้กับเควินอยู่ดี ดูอย่างเมื่อกี้นี้สิ แม้แต่แจ็คยังดึงผมออกมาเลย

หมดกระป๋องแรก ผมก็รีบหยิบเอากระป๋องถัดไปมาต่อทันที แจ็คถึงกับกุมขมับทันที “มึงกินขนาดนั้นไม่ได้มึงก็รู้”

ผมก็รู้ ว่าผมจะเมามาก เพราะผมไม่ได้คอแข็งเหมือนกับแจ็ค ปกติดื่มแค่แก้วเดียวผมก็เมาแล้ว ดังนั้น แจ็คจึงมักจะอยู่กับผมตลอด ไม่ยอมให้ดื่มเกินแก้วเดียว หรือกระป๋องเดียวเด็ดขาด เพราะหลังจากนั้น ผมจะเมา จนดูแลตัวเองแทบไม่ได้

สติที่ยังพอจะรับรู้เรื่องราวต่างๆ ได้ของผมบอกให้ผมรู้ว่าตอนนี้แจ็ครีบลุกขึ้นไปซื้อน้ำเปล่ามาสองขวด

แต่ผมก็พยายามจะเปิดกระป๋องที่สาม แม้แจ็คจะพยายามยัดเยียดขวดน้ำเปล่าใส่มือผม

“มึงแม่งเหี้ย กูอยากจะไปปลอบเควินมึงก็ลากกูออกมา กูอยากจะอยู่กับเควิน มึงก็ไม่เคยสนับสนุน นี่มึงเป็นอะไรกับกูมากหรือเปล่า? ไอ้เอิ้นเหี้ยนั่นก็อีกตัว จะกันอะไรกูนักหนา ก็กูรักเค้านี่! ทำไมไม่ปล่อยให้กูอยู่กับเค้า!?”

“ธัชชัย มึงเมาแล้ว กลับเหอะ!”

“ทำไมวะ ทำไมกูจะเอาเควินมาครอบครองบ้างไม่ได้วะ คนอื่นใช้เวลากับเควินมากพอแล้วนะเว่ย!”

กระป๋องเบียร์ที่เพิ่งเปิดใหม่ในมือ ผมไม่ได้กะจะดื่มมันตั้งแต่แรกอยู่แล้ว ผมสะบัดข้อมือสาดน้ำสีเหลืองทองที่ยังซ่าอยู่เต็มแรงใส่หน้าไอ้แจ็คไปเต็มๆ

“**โอ๊ย! ไอ้เหี้ย! แสบ!**”

แจ็คร้องออกมาด้วยความเจ็บปวดทันทีที่ฟองเบียร์และแอลกอฮอล์พุ่งเข้าตาเขาทั้งสองข้าง ตัวเขาสั่นเทิ้มเพราะความแสบที่แล่นจี๊ดเข้าไปในดวงตาจนลืมตาไม่ขึ้น

ผมไม่รอให้มันหายแสบหรอกครับ ผมโยนกระป๋องเบียร์ทิ้งลงบนโต๊ะจนมันกลิ้งขลุกขลักแล้วเดินตรงไปนอกร้านทันที ทิ้งให้แจ็คควานหาทิชชูหรือน้ำเปล่ามาชะล้างตาอย่างลนลานอยู่ข้างหลัง โชคดีที่จังหวะนี้เป็นจังหวะที่ผมเห็นเควินลุกออกไปห้องน้ำพอดี

เดี๋ยวสิ... นั่นใช่เควินมั้ย?

ตาผมพร่ามัวจนผมต้องพยายามส่ายหัวอยู่หลายครั้งเพื่อปรับภาพให้ชัดขึ้น

หลังจากมั่นใจว่าเป้าหมายนั้นถูกคน ผมเลยรีบเดินตามเข้าห้องน้ำไปทันที...
